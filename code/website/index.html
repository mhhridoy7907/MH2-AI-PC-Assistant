About the project

MH2 AI PC Assistant is a personal PC automation and remote-control project developed by Murad Hasan Hridoy.

About MH2 AI

MH2 AI aims to make everyday computer operations easier through voice and text interaction, supported automation, and a future phone-to-PC workflow. The Windows-side Python module provided for this build specifically implements a WhatsApp call workflow and supporting audio, speech, and state-management components.

  • Existing Python call automation reference
  • Website product and contact experience
  • Designed for future authorized PC integration
